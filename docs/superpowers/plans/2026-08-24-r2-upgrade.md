# R2 软件升级检测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 已装软件与 catalog 版本对比，检测到更高版本时在已装列表行内显示「可升级」，一键直装新版（新旧并存、不自动启动）。

**Architecture:** 后端加纯函数 `compare_versions` + `compute_upgrades`，暴露 `check_upgrades` 命令（纯内置 catalog 对比，立即返回）；前端列表加载时先显示检测结果，再并行调已有 `fetch_remote_versions_for` 在线刷新（失败静默回退）。升级复用 `install_software`（新目录新记录）+ 全局 `installStore` 进度面板。

**Tech Stack:** Rust (tauri command + serde)、Vue 3 Composition API、Pinia (`useInstallStore`)。

## Global Constraints

- 所有代码在 dev 分支上开发（本仓库规则：禁止直接改 master）。
- 目标版本 = catalog 中「高于当前版本的最高版本」，允许跨大版本。
- 升级只安装**不自动启动**；新旧并存，旧版记录/目录保留。
- 在线刷新走已有 `fetch_remote_versions_for` 命令，前端 `Promise.allSettled` 并发、失败静默。
- 版本比较规则：数字分段比较（`5.7.44 < 8.0.36`、`7.4.9 < 7.10.0`）；任一段非数字退化为字符串比较。

/// 数字分段版本比较：5.7.44 < 8.0.36；7.4.9 < 7.10.0；
/// 任一段含非数字时退化为字符串比较（v1 < v2）。
fn compare_versions(a: &str, b: &str) -> std::cmp::Ordering {
    use std::cmp::Ordering;
    let ap: Vec<&str> = a.split('.').collect();
    let bp: Vec<&str> = b.split('.').collect();
    for i in 0..ap.len().min(bp.len()) {
        match (ap[i].parse::<u64>(), bp[i].parse::<u64>()) {
            (Ok(x), Ok(y)) if x != y => return x.cmp(&y),
            (Ok(_), Ok(_)) => {}
            _ => return a.cmp(b),
        }
    }
    ap.len().cmp(&bp.len())
}

#[cfg(test)]
mod tests {
    use super::compare_versions;
    use std::cmp::Ordering;

    #[test]
    fn version_cross_major() {
        assert_eq!(compare_versions("5.7.44", "8.0.36"), Ordering::Less);
    }
    #[test]
    fn version_equal() {
        assert_eq!(compare_versions("8.0.36", "8.0.36"), Ordering::Equal);
    }
    #[test]
    fn version_prefix_longer_is_greater() {
        assert_eq!(compare_versions("1.31.2", "1.31"), Ordering::Greater);
    }
    #[test]
    fn version_numeric_segment() {
        assert_eq!(compare_versions("7.4.9", "7.10.0"), Ordering::Less);
    }
    #[test]
    fn version_non_numeric_falls_back_to_string() {
        assert_eq!(compare_versions("v1", "v2"), Ordering::Less);
    }
}

/// 计算已装软件的升级目标：catalog 中高于当前版本的最高版本
fn compute_upgrades(installed: &[InstalledSoftware], catalog: &Catalog) -> Vec<crate::models::software::UpgradeInfo> {
    use crate::models::software::UpgradeInfo;
    let mut out = Vec::new();
    for sw in installed {
        if sw.is_custom {
            continue;
        }
        let Some(entry) = catalog.entries.iter().find(|e| e.key == sw.key) else {
            continue;
        };
        let target = entry
            .versions
            .iter()
            .map(|v| v.version.as_str())
            .filter(|v| compare_versions(v, &sw.version) == std::cmp::Ordering::Greater)
            .max_by(|x, y| compare_versions(x, y))
            .map(|s| s.to_string());
        out.push(UpgradeInfo {
            key: sw.key.clone(),
            name: entry.name.clone(),
            current_version: sw.version.clone(),
            target_version: target,
        });
    }
    out
}

/// 升级检测：基于当前 catalog（含内置 + 远程合并缓存）纯本地对比，立即返回
#[tauri::command]
pub fn check_upgrades(manager: State<'_, Arc<SoftwareManager>>) -> Vec<crate::models::software::UpgradeInfo> {
    let catalog = manager.get_catalog();
    let installed = manager.get_installed();
    compute_upgrades(&installed, &catalog)
}
```

const installStore = useInstallStore()
// key → 目标升级版本（无可升级则无该 key）
const upgradeMap = ref<Record<string, string>>({})

function applyUpgrades(list: UpgradeInfo[]) {
  const map: Record<string, string> = {}
  for (const u of list) {
    if (u.target_version) map[u.key] = u.target_version
  }
  upgradeMap.value = map
}

/** 内置检测先行返回；随后并行在线刷新，失败静默回退 */
async function loadUpgrades() {
  try {
    const list = await invoke<UpgradeInfo[]>('check_upgrades')
    applyUpgrades(list)
    refreshUpgrades(list.map((u) => u.key))
  } catch (e) {
    console.error('check_upgrades failed:', e)
  }
}

async function refreshUpgrades(keys: string[]) {
  const uniq = [...new Set(keys)]
  await Promise.allSettled(
    uniq.map((k) => invoke('fetch_remote_versions_for', { key: k })),
  )
  try {
    applyUpgrades(await invoke<UpgradeInfo[]>('check_upgrades'))
  } catch (e) {
    console.error('refresh upgrades failed:', e)
  }
}

/** 一键升级：安装 catalog 中的目标版本（新旧并存，不自动启动） */
async function onUpgrade(item: InstalledSoftware) {
  const target = upgradeMap.value[item.key]
  if (!target) return
  try {
    const installId = (await invoke('install_software', {
      params: { key: item.key, version: target, mirror_index: 0, set_as_default_jre: false },
    })) as string
    installStore.createTask(installId, item.key, `${item.name} → ${target}`)
  } catch (e) {
    console.error('upgrade failed:', e)
  }
}
```

2. 若实例运行中（status Running/Starting）→ `lifecycle::stop_one(pid)` 等待停止。

4. 调用 `download_and_extract` 装新版到 `apps/<key>/<new_ver>`（新目录）。
5. **迁移数据/配置**：从 `.bak` 复制 `provider.data_dirs()`（默认 `data/`，nginx 覆盖输出 `sites-data/`、`conf/sites`）+ `provider.config_file_path()` 指向的文件到新目录（目标父目录存在则建）。
6. **记录合并**：删除旧 installed 记录；对 installer 新记录（`download_and_extract` 后由 `upgrade_software` 自己 add？——安装前先 `manager.remove_installed(old_id)`，再 `manager.add_installed(new_installed)` 并把旧记录 `config/auto_start_on_app_start/startup_order/port` 拷给新记录）。
7. emit `completed`（install_id 由前端 createTask 时给定）。

实现时参照 `install_software` 的事件/错误风格；不用通用 migrate 框架（ponytail：各软件数据目录差异大，先按 data_dirs + config_file_path + nginx 站点区迁移）。

- [ ] **Step 2: 实现 `rollback_software` 命令**

```
1. 取 installed（按 id），解析 key、cur_version、apps/<key>/<cur> 目录。
2. 扫描 apps/<key>/*.bak 找到备份目录（old_ver）；无 → Err("无可用回滚备份")。
3. 若 Running/Starting → lifecycle::stop_one(pid) 等待停止。
4. 新目录 rename → apps/<key>/<cur>.off（保留），旧 .bak rename → apps/<key>/<old_ver>。
5. 更新 installed 记录：version=old_ver、name=format!("{name不含版本} {old_ver}")、install_path=format!("{key}/{old_ver}")；config/auto_start/startup_order/port 保持。
6. 返回 Ok，前端刷新列表。
```

（与 Task 6 的 `upgrade_software` 对称；参考其事件/错误风格。rename 用 `std::fs::rename`。）
